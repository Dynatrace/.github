## ObsLab

**ObsLab** is a collection of hands-on observability labs designed to help
developers and practitioners learn by doing.

The labs cover topics across Dynatrace and the broader observability ecosystem,
including OpenTelemetry, log ingestion, release validation, performance
testing, AI observability, Kubernetes, and application security.

### OpenTelemetry and data ingestion

- [`obslab-otel-collector-data-ingest`](https://github.com/Dynatrace/obslab-otel-collector-data-ingest)  
  Ingest logs, metrics, and traces using the Dynatrace OpenTelemetry Collector.

- [`obslab-syslog`](https://github.com/Dynatrace/obslab-syslog)  
  Ingest syslog data into Dynatrace using the OpenTelemetry Collector.

- [`obslab-live-debugger-otel`](https://github.com/Dynatrace/obslab-live-debugger-otel)  
  Explore live debugging and OpenTelemetry instrumentation.

### Reliability and performance

- [`obslab-release-validation`](https://github.com/Dynatrace/obslab-release-validation)  
  Use Grafana k6, Dynatrace business events, workflows, and Site Reliability
  Guardian to validate releases.

- [`obslab-jmeter`](https://github.com/Dynatrace/obslab-jmeter)  
  Explore integration between Apache JMeter and Dynatrace.

- [`obslab-k6`](https://github.com/Dynatrace/obslab-k6)  
  Stream Grafana k6 metrics into Dynatrace in a hands-on exercise.

### Troubleshooting

- [`obslab-log-problem-detection`](https://github.com/Dynatrace/obslab-log-problem-detection)  
  Detect problems in logs with Dynatrace.

### AI observability

- [`obslab-llm-observability`](https://github.com/Dynatrace/obslab-llm-observability)  
  Build an LLM-powered application and explore its observability with Dynatrace.

### Kubernetes

- [`obslab-predictive-kubernetes-scaling`](https://github.com/Dynatrace/obslab-predictive-kubernetes-scaling)  
  Explore predictive auto-scaling for Kubernetes workloads.

### Application security

- [`obslab-unguard`](https://github.com/Dynatrace/obslab-unguard)  
  Detect and block security vulnerabilities with Dynatrace.
